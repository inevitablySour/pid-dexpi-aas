# Shown-lines test fixtures

The app's model output on drawings it never saw, with the labels kept as `_truth`
(see `tests/test_shown_lines.py`).

- `lightup_*.json`: the team drawing `subprojects/LightUp/P&ID gramflow reactor V3`.
- `open100_*.json`: derived from the OPEN100 sheets of **PID2Graph** (Stürmer, Graumann and
  Koch; Zenodo record 14803338, https://zenodo.org/records/14803338), licensed under
  Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0). These files are
  shared under the same licence.
